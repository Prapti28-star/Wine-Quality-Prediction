#  Wine Quality Prediction (Machine Learning Project)

## Overview

This project predicts wine quality using machine learning models.
The dataset contains physicochemical properties of wine such as acidity, sugar, pH, alcohol, etc.

---

## Tech Stack

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

---

## Workflow

1. Data Loading & Understanding
2. Data Cleaning (No missing values)
3. Exploratory Data Analysis (EDA)
4. Feature Engineering (Binary Classification)
5. Train-Test Split
6. Feature Scaling
7. Model Training:

   * Logistic Regression
   * KNN
   * Decision Tree
   * Random Forest
   * SVM
8. Model Evaluation
9. Hyperparameter Tuning (GridSearchCV)

---

## Results

* Best Model: Random Forest
* Accuracy: ~90%
* Tuned SVM Accuracy: ~89%

---

## Key Insights

* Most wines fall between quality 5–6
* Dataset is imbalanced
* Ensemble models perform best
